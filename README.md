# deepthinking

仅显式调用的学习辅助 Skill。回答前查证可靠且适时更新的资料，讲清原理、前提和边界，通过适量的知识关联与思考引导帮助学习迁移。

## 能力

- 按问题选择教材、原始研究、综述、官方文档或行业报告，标注来源与不确定性。
- 根据当前对话调整深度，诊断错误前提和常见误解。
- 先回答问题，再解释机制、适用条件与反例。
- 适度拓展前置知识、相邻理论和应用，解释学习价值。
- 按需提供小型理解验证、复习题、知识关系图和阶段总结。

## 安装与调用

将本仓库克隆到本机技能目录中的 `deepthinking` 文件夹，例如：

```sh
git clone https://github.com/Yu03-6/deepthinking.git ~/.codex/skills/deepthinking
```

若目标目录已存在，请先检查现有版本，勿直接覆盖。根据宿主的技能发现机制刷新技能或开启新对话。

在支持技能选择的界面中显式选择/@ `deepthinking`，或使用明确的调用语法：

```text
$deepthinking 为什么增加样本量通常可以改善估计？请先直观解释，再讲条件和局限。
```

`agents/openai.yaml` 设置 `allow_implicit_invocation: false`，禁止默认隐式加载。当前学习主题的连续追问沿用此模式；退出或切换无关任务后停止，新主题需重新调用。宿主需支持该调用策略；仅复制 SKILL.md 到其他产品不会自动获得相同的调用控制。

可以指定“简短回答”“深入推导”“给一个练习”或“总结本轮学习”。练习不是获取完整解释的门槛。

## 资料与隐私边界

需要可用的搜索/浏览工具才能完成实时查证。无法检索时会说明限制，不冒称掌握最新研究。不自动建立跨对话学习档案或创建提醒。

本仓库包含技能指令与调用配置，不包含搜索服务或模型运行环境。学习效果取决于执行模型、可用工具与资料质量。
